# NPF

The [Noise Protocol Framework](https://noiseprotocol.org), revision 34, in Zig.

All 38 handshake patterns, the `psk` and `fallback` modifiers, Noise Pipes, X25519 and X448, ChaChaPoly and AESGCM, SHA256, SHA512, BLAKE2s and BLAKE2b.

Verified against 1064 official test vectors. Invalid handshake patterns are rejected at compile time.

Primitives come from `std.crypto`, except the Goldilocks field arithmetic behind X448, which is generated by [fiat-crypto](https://github.com/mit-plv/fiat-crypto) and carries machine-checked proofs of correctness and of its limb bounds. It is vendored in `src/fiat/`.

## Use

```zig
const npf = @import("npf");

const XX = npf.Protocol("Noise_XX_25519_ChaChaPoly_SHA256");

var hs = try XX.init(.initiator, .{ .s = static, .rng = rng });

var buf: [npf.max_message_len]u8 = undefined;
const n = try hs.writeMessage("hello", &buf);
// send buf[0..n], read the reply, repeat until hs.isFinished()

var t = try hs.split();
const len = try t.send.encryptWithAd("", "data", &buf);
```

The protocol name is resolved at compile time, so an unknown pattern or algorithm is a compile error rather than a runtime one.

Requires Zig 0.17.

|---|---|
| `zig build test` | everything |
| `zig build test-fast` | everything except the vectors |
| `zig build test-vectors` | the official vectors |
| `zig build test-rejects` | patterns that must fail to compile |

## What this does NOT do

Noise is a framework, not a complete protocol. Section 13 of the spec leaves these to you:

- **Framing.** A Noise message carries no length. Messages are at most 65535 bytes, so a 16 bit big-endian prefix is the usual choice.
- **Session termination.** An attacker can truncate a message stream. Signal the end inside your payloads.
- **Negotiation.** Deciding which Noise protocol to speak, and telling an `IK` message from an `XX` one, is yours. See `Pipe` in `src/pipe.zig`. Doing this badly invites rollback attacks.
- **Authorisation.** A handshake proves the peer holds the private key for a static public key. Whether that key is one you accept is your policy.
